\# 📖 Руководство пользователя Photoprotocol



В этом документе собраны все варианты просмотра зашифрованного контента для подписчиков, а также инструкции по пакетной обработке для авторов.



\## 👤 Инструкции для пользователей



\### 1. Просмотр через браузер (без сторонних менеджеров скриптов)

Подходит для Chromium-браузеров (Google Chrome, Яндекс.Браузер, Microsoft Edge, Brave, Opera):

1\. Скачайте архив со свежей версией из раздела \*\*\[Releases](https://github.com)\*\*.

2\. Распакуйте папку `extension` в любое удобное место на диске.

3\. Откройте в браузере страницу управления расширениями: `chrome://extensions/`.

4\. Включите тумблер \*\*«Режим разработчика»\*\* в правом верхнем углу и нажмите \*\*«Загрузить распакованное расширение»\*\*.

5\. Укажите распакованную папку `extension`.

6\. Перейдите на страницу с зашифрованными артами, кликните по иконке расширения, выберите режим, введите секретный ключ и нажмите \*\*«Применить и обновить»\*\*.



\### 2. Просмотр через браузер с установленным менеджером юзерскриптов

Подходит для пользователей Violentmonkey или Tampermonkey (включая Firefox и Safari):

1\. Откройте прямую ссылку на скрипт:  

&#x20;  👉 \*\*\[Установить photoprotocol.user.js](https://github.io)\*\*

2\. Подтвердите установку скрипта в открывшемся окне менеджера.

3\. Перейдите на страницу с изображениями, откройте настройки скрипта через иконку расширения (или нажмите `Alt + P`), укажите режим, введите ключ и сохраните параметры.



\### 3. Просмотр на ПК вне браузера (Telegram Desktop, Discord и др.)

Используйте легковесный автономный плеер:

1\. Скачайте архив с релизом из раздела \*\*\[Releases](https://github.com)\*\* и распакуйте папку `appdes`.

2\. \*\*Если изображение отправлено файлом:\*\*

&#x20;  \* Кликните по файлу правой кнопкой мыши -> \*\*«Открыть с помощью»\*\*.

&#x20;  \* Выберите файл `PhotoprotocolViewer.exe` из папки `appdes`.

&#x20;  \* В окне программы нажмите кнопку \*\*«Ключ»\*\*, введите секретный пароль и выберите нужный режим дешифровки.

3\. \*\*Если изображение отправлено обычной картинкой:\*\*

&#x20;  \* Нажмите на картинку правой кнопкой мыши -> \*\*«Сохранить как»\*\*.

&#x20;  \* Запустите `PhotoprotocolViewer.exe` и нажмите кнопку \*\*«Открыть»\*\* (или просто перетащите файл в окно).

&#x20;  \* Задайте секретный ключ по кнопке \*\*«Ключ»\*\*.



> \[!TIP]

> В программе можно листать изображения стрелками на клавиатуре (`←` / `→`) или колесиком мыши, переключать режимы клавишей `M` и переходить в полноэкранный режим клавишей `F11`.



\### 4. Просмотр на мобильных устройствах (Android)

1\. Скачайте установочный пакет из раздела \*\*\[Releases](https://github.com)\*\* (папка `appand` / файл `.apk`).

2\. Откройте загруженный `.apk` файл и подтвердите установку (если появится предупреждение Google Play Protect — нажмите \*\*«Подробнее»\*\* -> \*\*«Все равно установить»\*\*).

3\. \*\*Просмотр из мессенджера:\*\* откройте картинку в Telegram, нажмите \*\*«Поделиться»\*\* (или «Открыть с помощью») и выберите \*\*PhotoprotocolViewer\*\*.

4\. \*\*Просмотр локальных файлов:\*\* нажмите иконку \*\*📁\*\* внутри приложения и выберите сохраненную картинку из галереи.

5\. Выберите режим, введите секретный ключ и нажмите \*\*«Применить»\*\*.



\### 5. Просмотр через Telegram Mini App (без установки софта)

> \[!NOTE]

> Способ работает только для публичных каналов без возрастной отметки 18+.

1\. Перейдите по ссылке: \*\*\[t.me/photoprotocol\_viewer\_bot/gallery](https://t.me)\*\*.

2\. Примите условия использования.

3\. Введите название канала без символа `@` и подтвердите ввод.

4\. Укажите секретный ключ и нажмите \*\*«Применить»\*\*.

5\. Если в приложении появляется ошибка \*Failed to fetch\* или \*Http status 408\* — значит канал защищен отметкой 18+, и Telegram не отдает изображения внешнему веб-просмотрщику. В таком случае воспользуйтесь Android-клиентом или десктопным приложением.



\## 🛠️ Инструкции для авторов (Шифрование контента)



Подготовьте файлы из папки `python`, скачанной из раздела \*\*\[Releases](https://github.com)\*\*.



\### 1. Одиночные изображения (Системный Python в PATH)

\* Перетащите одну или несколько картинок мышкой прямо на файл \*\*`DROP\_HERE.bat`\*\*.

\* Следуйте коротким подсказкам в открывшемся окне консоли (выберите режим и укажите ключ).



\### 2. Одиночные изображения (Portable Python / ComfyUI)

1\. Поместите исходное изображение в папку скрипта.

2\. Кликните по адресной строке проводника в папке, введите `cmd` и нажмите Enter.

3\. Активируйте локальное окружение (например: `call environment.bat`).

4\. Запустите скрипт вручную:

&#x20;  ```cmd

&#x20;  DROP\_HERE.bat "ваше\_изображение.png"

&#x20;  ```

5\. Задайте параметры в диалоге консоли.



\### 3. Пакетная обработка по папкам (Стандартный режим)

Подходит для небольших пачек или ПК со стандартным процессором:

1\. Перенесите всю пачку файлов в папку \*\*`input`\*\*.

2\. Запустите командную строку в папке скрипта (`cmd` в адресной строке проводника).

3\. При необходимости инициализируйте окружение (`call environment.bat`).

4\. Запустите пакетную обработку:

&#x20;  ```cmd

&#x20;  call BATCH\_ENCRYPT.bat

&#x20;  ```

5\. Готовые файлы с хронологической нумерацией появятся в папке `output`.



\### 4. Пакетная обработка по папкам (Многопроцессорный режим)

Оптимально для тяжелых апскейлов и пачек на 500–1000+ изображений на многоядерных процессорах:

1\. Перенесите изображения в папку \*\*`input`\*\*.

2\. Запустите командную строку в текущей папке.

3\. Инициализируйте окружение (`call environment.bat`), если используется портативная сборка.

4\. Запустите параллельный скрипт:

&#x20;  ```cmd

&#x20;  call BATCH\_ENCRYPT2.bat

&#x20;  ```

5\. Скрипт задействует все свободные ядра процессора, сохраняя плавность системы для браузера и фоновых задач.

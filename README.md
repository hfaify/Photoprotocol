## 💡 Зачем и для кого это создано?

Идея проекта родилась не на пустом месте: после серии скоординированных жалоб и волн страйков мне последовательно заблокировали практически все ресурсы, где годами публиковался контент. Группа за группой, канал за каналом - пока площадок для комфортной публикации почти не осталось.

Постоянно пересоздавать паблики и уводить за собой аудиторию по цепочке бесконечных «резервных ссылок» - верный путь к потере читателей и выгоранию. Поэтому я решил подойти к проблеме принципиально иначе: **не бегать от платформ, а лишить модераторов и спам-ботов самого повода для блокировки**.

> **Суть решения:**  
> Вы выкладываете зашифрованный арт в открытый доступ на привычной площадке (VK, Telegram и др.).  
> • **Для хейтеров, ботов и живых модераторов** пост выглядит как бессмысленный цветной шум или абстрактный глитч - придраться формально не к чему.  
> • **Для ваших подписчиков**, установивших лёгкое расширение и указавших секретный ключ, картинка в ту же секунду собирается обратно в чистый оригинальный арт прямо в ленте.

Все остаются в выигрыше: вам не нужно менять платформы, подписчикам не нужно скакать по зеркалам, а автоматические фильтры площадок просто проходят мимо.

## ⚙️ Как устроен комплекс

**Photoprotocol** состоит из двух согласованных компонентов:
1. **Desktop-энкодер (Python):** шифрует изображение выбранным алгоритмом по заданной кодовой фразе (сиду).
2. **Браузерный дешифратор (Chromium-расширение):** на лету перехватывает изображение на веб-странице, считывает пиксели через Canvas и разворачивает исходник в оперативной памяти без отправки данных на сторонние серверы.

### Доступные режимы маскирования

| Режим | Как работает | Устойчивость к JPEG | Назначение |
| :--- | :--- | :---: | :--- |
| **🧩 Тайлинг (Мозаика)** | Нарезает арт на блоки 32×32 px, хаотично тасует их по алгоритму Фишера - Йетса, случайно вращает и зеркалит. | **Высокая** *(рекомендуется)* | Публикация обычными постами в ленту VK, Telegram и веб-галереи. |
| **📺 Шум (XOR-маска)** | Превращает полотно в монолитный попиксельный белый шум на базе SHA-256 сида. | **Нет** *(только PNG)* | Публикация файлами без сжатия (документы, архивы, облачные диски). |

## 🚀 Руководство пользователя

### 1. Подготовка и шифрование (Для автора)

#### Вариант A: Если Python установлен в системе
1. Распакуйте содержимое папки `python` в любое удобное место на диске.
2. Перетащите нужную картинку (или сразу несколько) мышкой на файл **`DROP_HERE.bat`**.
3. Следуйте подсказкам в окне: выберите метод шифрования, введите секретный ключ (или нажмите `Enter` для значения по умолчанию).
4. Заберите готовый зашифрованный файл с суффиксом `_shielded` рядом с оригиналом.

#### Вариант B: Если вы используете Portable Python (например, из сборки ComfyUI)
1. Поместите исходное изображение в папку со скриптом.
2. Кликните по адресной строке в папке, введите `cmd` и нажмите `Enter`.
3. Инициализируйте окружение сборки:
   ```cmd
   call environment.bat
   ```
4. Запустите пакетный файл, передав имя файла аргументом:
   ```cmd
   DROP_HERE.bat "ваше_изображение.png"
   ```
5. Задайте параметры в диалоге консоли.

### 2. Установка расширения (Для подписчиков)

> [!NOTE]
> На данный момент расширение оптимизировано для всех Chromium-браузеров: **Google Chrome**, **Яндекс.Браузер**, **Microsoft Edge**, **Brave**, **Opera**.

1. Скачайте репозиторий (или загрузите архив из раздела **Releases**) и извлеките папку `extension`.
2. Откройте в браузере страницу управления расширениями:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу окна активируйте тумблер **«Режим разработчика»** (*Developer mode*).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) в левом верхнем углу.
5. Укажите путь к распакованной папке `extension`.
6. На панели инструментов нажмите на иконку **Photoprotocol**, выберите используемый автором метод (`Мозаика` или `Шум`), вставьте секретный ключ и нажмите **«Применить»**.

> [!TIP]
> Если вы хотите временно приостановить дешифровку и сэкономить ресурсы системы, просто выберите в списке режим **«⏸️ Отключено»**.
